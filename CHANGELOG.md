- Add the five native normal mouse-button assignments in both F75 layers with exact record fixtures, profile/readback support and existing reviewed transaction safeguards; preserve repeat/unknown records raw. No host input injection or automatic hardware write.

- Apply the public-documentation allowlist to the general native build script, removing stale private staging notes and adding dependency notices. Regression tests preserve original docs/Git metadata and reject symlinked staging.

- Recover F98 Pro's own RGB branch,20 presets,0–5 controls and scalar-versus-per-key color encoding through REA/Ghidra executable/DLL analysis. Add independent offline scalar/per-key data codecs, local lighting/per-key drafts and per-effect disabled controls; keep all F98 hardware access disabled.
- Migrate older schema1 F98 lighting-null profiles while preserving their identity, assignments and macros; loading leaves saved bytes unchanged and persistence remains explicit.

- Keep generated duplicate profile and macro names within the Rust UTF-8 byte limit and editor character limits, without splitting Unicode characters. Preserve independent event copies.

- Recover F2088 Advanced Installer containers statically; add a tested bounded extractor, partial103-position local workspace and independent eight-byte panel-lighting codec. Omit unknown Fn/LED/matrix roles and keep all F2088 hardware access disabled.

- Resolve after-event application macro timing through native disassembly; add bounded offline Rust/CLI/GUI wire inspection with exact fixtures and no macro HID command path.
- Extend local macro editing with key changes, insertion/reorder/duplicate/clear,100-event paging and accurate explicit-delay/chord preview with cancellation on profile changes.
- Reconstruct the original macro sidebar's six18-pixel toolbar actions from native constructor evidence, with bounded optional local icons and independent fallbacks.

- Implement an experimental model-specific F87/F108/H108 bounded read adapters: exact identity and descriptor gates, configuration/palette/base/per-key captures, private immutable capture storage, explicit simulated fixtures and local lighting-draft projection. No new-model configuration writes.
