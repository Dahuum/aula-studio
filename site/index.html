REVIEW BEFORE YOU WRITE

A clear path from draft to device.

No automatic configuration on startup, reconnection or local profile save. Supported writes use typed Rust transactions and preserve unrelated data.

  1. 01Edit

    Work on a local draft.

  2. 02Back up

    Read and retain the before-state.

  3. 03Review

    See the exact device and changes.

  4. 04Write

    Confirm the scoped operation.

  5. 05Read back

    Success requires a match.

Reviews expire after 120 seconds and are single use. Failures remain unconfirmed, without automatic retries or rollback. Backups and scoped restoration are not firmware flashing or factory resets.

A FEW GOOD QUESTIONS

Before you plug in.

Does this fully replace the Windows software?

Not yet. Real reviewed operations exist, but hardware coverage and the original-UI recreation are incomplete. Onboard macro uploads, wireless configuration and several device settings remain unavailable or under investigation.

Does it work over Bluetooth or the 2.4 GHz dongle?

Configuration currently targets USB wired mode. The receiver can be identified, but its configuration framing has not been verified. Wireless typing and wireless configuration are separate capabilities.

Do I need root?

Run the app as your normal user. The optional narrow udev rule grants the active local seat access to the supported wired device. The app does not replace kernel drivers or install a privileged background service.

Can I try it without changing my keyboard?

Yes. Explicit demo mode works without a device and applies only to an in-memory simulation. Local profile saving and macro preview do not configure hardware or inject keys into other applications.

Is the original artwork included?

No. The release uses independently drawn assets. The app can optionally read your own local extracted artwork, but never uploads or redistributes it. Several panel layouts, fonts and keyboard details still differ from the original UI.

Is it free and open source?

The original code is MIT licensed. You can inspect, build, modify and contribute under that license; dependencies and attributed fixtures retain their own notices. This is an independent community project, not an official AULA product.
