05 / QUESTIONS

Before installing.

Does this fully replace the Windows software?

Not yet. Hardware coverage and the original UI recreation are incomplete. Onboard macro uploads, wireless configuration and several device settings remain unavailable or under investigation.

Is this on npm, AUR or Flathub?

No npm package, AUR entry or Flathub listing is published. Use a native package above. npm is only needed when building the frontend from source. A reviewed AUR recipe is available in the repository; a recipe is not a published AUR package.

Does it run on every Linux distribution?

No single binary covers all Linux systems. The downloads target x86_64 GNU/Linux with GTK 3, WebKitGTK 4.1 and glibc 2.36 or newer. The installation guide distinguishes tested distributions from compatible but untested derivatives. Alpine/musl, ARM binaries and older distributions are not covered by these packages.

Do I need root or a new driver?

Run the app as your normal desktop user. Packages include a narrow uaccess rule for the wired F75. Reconnect after installation. The app does not replace drivers or install a privileged background service.

Can I try it without changing my keyboard?

Yes. Choose Enter demo mode in the app. Demo changes stay in memory; local profiles and macro preview do not configure hardware or inject input into other applications.

Can more keyboards be supported without owning them?

Static analysis can recover protocols, layouts and formats from their Windows software. Communication, hardware revisions and safe persistence still need physical validation. Researched models must be labeled separately from hardware-verified models. Expansion policy ↗
