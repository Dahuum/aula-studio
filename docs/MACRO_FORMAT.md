## Bounded format

A raw record begins with one byte containing the UTF16LE name's byte length, followed by that name and four-byte events. At most30 UTF16 code units; no NUL or truncation is accepted by this implementation.

For each event, byte0 contains kind in bits4–6, delay bits16–19 in bits0–3 and release flag80 for keyboard/modifier/mouse-button events. Bytes1/2 contain the remaining delay in big-endian order, and byte3 is the usage/value. Kind0 is ordinary keyboard;1 modifier;2 mouse button;3/4 X/Y movement;5 wheel. Release80 is established from the recorder/action/wire chain. The raw codec supports these observed kinds; the local-macro converter deliberately accepts only keyboard actions.

The offline converter accepts ordinary usages present in the supplied native table (4–101,104,133,135–139,144–145) and modifier usages224–231. Modifier events use kind1. No application/vendor usages or other model's actions are guessed.

Local delay events accumulate on the preceding raw key event. Adjacent delays are combined exactly; a sum exceeding0xfffff is rejected. Nonzero leading silence has no established representation: the native wire converter stops at virtual-key0 rather than emitting a no-op, so leading nonzero delays are rejected. Empty/delay-only sequences and unbalanced actions are rejected. The ordinary local editor still supports leading delays; this restriction applies only to original F75 wire inspection.

The pool begins with `[offset_le16, size_le16]` for every record, then contiguous records. A single-record preview begins with offset4 and its exact record length. The default4096-byte application buffer is not a measured hardware capacity; both record and pool bounds are enforced. No transfer packet, binding or HID report is generated by the preview service.

Independent fixture: Shift press,25ms,A press,40ms,A release,5ms,Shift release,10ms, nameA:

```text
record: 02 41 00 10 00 19 e1 00 00 28 04 80 00 05 04 90 00 0a e1
pool:   04 00 13 00 [the 19 record bytes above]
```

## Use

Native F75 Macros → **Inspect F75 wire format (offline)** exports a JSON report from the Rust service. Fields explicitly state `hardware_validated:false`, `upload_available:false`, original-F75-G5 scope and remaining risks. This action is not offered as another model's format in Device library, and browser preview does not synthesize a native result.

```sh
# Use a local macro exported by the editor; no device or permissions needed.
./target/release/aula macro-preview path/to/exported-local-macro.json
```

This accepts the bounded schema1 `{ "schema_version":1, "macro": ... }` export and writes the inspection report to stdout. It performs no HID enumeration or access and changes no configuration.

Local editing additionally provides event key edits, before/after insertion, reordering, duplication, explicit clear,100-event pages and balanced-action validation. Offline playback uses the local explicit-delay timeline, groups simultaneous actions and cancels when the profile/sequence changes; it never injects input. Native integration tests exercise recording, edits, duplication and the real Rust inspector with all physical writes blocked.
